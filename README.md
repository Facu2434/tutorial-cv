# Tutorial CV

Presentación de 10 pantallas más 4 anexos cortos sobre cómo armar un currículum vitae. Un solo archivo (`index.html`), con el estilo de las clases de Geniso.

## Contenido

1. Portada
2. Qué es un CV
3. CV desordenado o claro
4. Las 4 partes
5. Qué va y qué no
6. Cómo escribirlo
7. El ATS
8. Una columna o dos
9. Paso a paso: CV a dos columnas con tabla sin bordes (Google Docs y Word)
10. Cuatro modelos para copiar
11. Anexos: A foto, B perfil online, C carta de presentación, D mejorar el CV con IA

## Publicar

En GitHub: Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Capturas reales del paso a paso

La pantalla 9 muestra un esquema de cada paso. Si existe una captura con el nombre de abajo dentro de `img/`, se muestra en lugar del esquema, sin tocar el HTML:

- Google Docs: `img/docs-1.png` a `img/docs-6.png`
- Word: `img/word-1.png` a `img/word-6.png`

El número es el paso (1 nombre y puesto, 2 insertar tabla, 3 ancho, 4 contenido, 5 color, 6 bordes).
